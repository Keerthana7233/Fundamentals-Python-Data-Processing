# Fundamentals of Python: Data Processing and Simple Algorithms

A simple Python program that processes bookstore inventory data from a CSV file.

## Features

- Book class with title, author, price, and stock
- Load inventory from CSV
- Calculate total inventory value
- Find the most expensive book
- Generate stock reports by author

## Files

- `inventory.py` - Main Python program
- `sample_inventory.csv` - Sample bookstore inventory

## How to Run

```bash
python inventory.py
